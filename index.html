So erhältst du deinen API-Key

In wenigen Schritten erstellst du deinen persönlichen API-Key.

  1. 1

    Entwicklerportal aufrufen

    Öffne die API-Key-Seite deines gewünschten Anbieters:

    Google AI Studio ↗ OpenAI Platform ↗ Anthropic Console ↗ OpenRouter ↗
  2. 2

    Konto erstellen / anmelden

    Logge dich beim gewählten Anbieter ein.

  3. 3

    API-Schlüssel generieren

    Klicke auf die blaue Schaltfläche "Create API key" bzw. "API-Schlüssel erstellen". Wähle ein bestehendes Projekt aus oder erstelle mit einem Klick ein neues Projekt.

  4. 4

    Schlüssel kopieren & hier einfügen

    Kopiere den generierten Schlüssel in die Zwischenablage und füge ihn im Reiter "Verknüpfen" ein.

💰 Welche Kosten entstehen?

Die anfallenden Kosten hängen vom gewählten Anbieter, Tarif und Modell ab. Bitte informiere dich direkt beim jeweiligen Anbieter über die aktuellen Preise und Konditionen.

🔄 Wie kann ich Modell oder Key nachträglich ändern?

Um Modell oder Key zu wechseln: Deaktiviere den Skill in der Alexa-App (unter Skills & Spiele → Magische Glaskugel), aktiviere ihn anschließend erneut und tippe auf "Konto verknüpfen". So kannst du jederzeit ein anderes KI-Modell oder einen neuen Key auswählen.

Lokale Verarbeitung & Account Linking: Die Eingaben auf dieser Seite werden lokal im Webbrowser verarbeitet. Der eingegebene API-Key wird beim Klick auf "Mit Alexa verknüpfen" über eine verschlüsselte Verbindung (HTTPS) im OAuth-Verfahren (Implicit Grant) als Access Token an Amazon Alexa übermittelt und dort dem jeweiligen Nutzerkonto zugeordnet.

Datenverarbeitung im Skill-Backend: Amazon Alexa wandelt gesprochene Anfragen in Text um. Bei Sprachanfragen an den Skill wird dieser Text zusammen mit dem hinterlegten Token über eine verschlüsselte Verbindung an das Backend des Skills (bereitgestellt über die Alexa-hosted Infrastruktur von Amazon innerhalb der Europäischen Union) übermittelt. Das Backend verarbeitet den API-Key und Fragetext ausschließlich flüchtig zur Beantwortung der Anfrage. Der Betreiber speichert und protokolliert weder Fragetexte noch API-Keys.

Weiterleitung an den KI-Anbieter & Drittlandübermittlung: Die Sprachanfrage wird zusammen mit dem hinterlegten API-Key an die Schnittstelle des jeweils ausgewählten KI-Anbieters übermittelt. Je nach gewähltem Anbieter kann eine Datenverarbeitung auch auf Servern außerhalb der Europäischen Union stattfinden.
